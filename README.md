BufferedReader: Serve para ler a entrada do usuário de forma eficiente (nesse caso, a base e a altura do triângulo).

try: O bloco onde colocamos o código que pode gerar erro.

catch: Captura os erros que ocorreram no bloco try e permite que o programa continue executando, mostrando uma mensagem de erro apropriada.

A área de um triângulo retângulo é calculada através da formula Base * Altura / 2.
